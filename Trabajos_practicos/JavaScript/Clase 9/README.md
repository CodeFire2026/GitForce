# Funciones en JavaScript

## 1. Funciones relacionadas con la manipulación de datos

Son funciones que permiten trabajar con datos, modificarlos, organizarlos o transformarlos según lo que necesite el programa.

**Puntos importantes:**
- Su nombre debe indicar qué acción realizan sobre los datos.
- Permiten modificar o transformar información.
- Deben ser fáciles de entender para otros desarrolladores.
- Pueden trabajar con textos, números, listas y otros tipos de datos.
- Su nombre debe ser claro y específico.

## 2. Eventos o interacción

Son funciones que se ejecutan cuando ocurre una acción o un evento, como hacer clic en un botón, escribir en un campo de texto o mover el mouse.

**Puntos importantes:**
- Su nombre debe describir la acción que realizan.
- Indican qué sucede cuando el usuario interactúa con la página.
- Permiten que una página web responda a las acciones del usuario.
- Deben ser fáciles de identificar y comprender.
- Su nombre debe relacionarse con el evento o la interacción que manejan.

## 3. Operaciones CRUD

CRUD es una sigla en inglés que representa las cuatro operaciones básicas para gestionar datos: crear, leer, actualizar y eliminar.

**Puntos importantes:**
- **Create (Crear):** permite agregar nuevos datos.
- **Read (Leer):** permite consultar o recuperar datos existentes.
- **Update (Actualizar):** permite modificar datos existentes.
- **Delete (Eliminar):** permite borrar datos.
- Los nombres de las funciones deben indicar claramente qué operación realizan.

## 4. Utilidades

Son funciones auxiliares que permiten realizar tareas específicas y reutilizables dentro de un programa, facilitando el desarrollo y evitando repetir código.

**Puntos importantes:**
- Su nombre debe describir claramente su propósito.
- Pueden utilizarse en diferentes partes del programa.
- Ayudan a organizar y simplificar el código.
- Permiten reutilizar operaciones que se necesitan con frecuencia.
- Deben realizar una tarea concreta y ser fáciles de comprender.
